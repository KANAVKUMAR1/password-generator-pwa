# Password Generator PWA

A simple, secure and offline-friendly random password generator built with plain HTML, CSS and JavaScript.

## GitHub Pages
Upload the **contents** of this folder to the root of a public GitHub repository. Keep `index.html` in the repository root.

Then enable **Settings → Pages → Deploy from a branch → main → /(root)**.

## PWABuilder
After GitHub Pages is live, paste the HTTPS GitHub Pages URL into PWABuilder and run the scan. This version includes real 192x192 and 512x512 PNG icons and a service worker.

## Local testing
Run `python -m http.server 8080` in this folder and open `http://localhost:8080`.
